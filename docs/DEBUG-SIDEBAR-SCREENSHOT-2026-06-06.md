## Preguntas/confusiones del usuario
1. **¿“Completas” y “Vísperas” son rezos?**  
   No: son **“horas litúrgicas”** (bloques del día). Dentro de cada hora se rezan varios **salmos/cánticos/oraciones** con títulos como “Nunc Dimittis”, etc.
2. **¿Qué es “Nunc Dimittis”?**  
   Es el nombre tradicional del **Cántico de Simeón**, que se reza en **Completas**. (En latín: *Nunc Dimittis* = “Ahora despides…”).
